# Quiesce Design System

This document is the source of truth for visual design. All UI work must conform to it.

## Aesthetic register

Private bank, not crypto dapp. Reference points: Wealthfront, Mercury, Stripe dashboard, Linear settings, Financial Times. Calm, deliberate, durable.

The product mediates inheritance and bequest — for many users, a religious and family obligation. The interface respects that gravity. No celebration, no whimsy, no marketing-speak.

## Hard prohibitions
- No gradients anywhere
- No glassmorphism, backdrop-blur, frosted glass
- No abstract decoration: no blobs, floating shapes, grid backgrounds, dot patterns
- No emoji in UI
- No purple, neon, electric blue, "web3" colors
- No oversized rounded corners (max 8px radius)
- No drop shadows by default — use 1px low-contrast borders
- No load animations, fade-ins, scroll-triggered reveals
- No marketing-speak in product copy — plain declarative language

## Typography
- Headlines: editorial serif (system: ui-serif, Georgia, Charter)
- Body: clean grotesque sans (system: Inter, ui-sans-serif)
- Monetary values: tabular-nums always
- Headlines large and confident: 56–80px on desktop
- Body 16–18px, line-height 1.55–1.65

## Color palette
- Background: #FAFAF7 (warm off-white)
- Text: #1A1A1A (near-black)
- Borders: #E5E5E5
- Muted text: #6B6B6B
- Accent (single use, primary actions only): #5C1A1A (deep oxblood)

## Layout
- Generous whitespace, 96–160px between major sections on desktop
- Left-aligned text everywhere except marketing hero
- 1px hairline dividers, never cards-with-shadows
- Wordmark only, no icon mark

## Copy register

Plain, declarative, slightly cool. The product does not flatter the user. It treats them as someone making a serious decision and gives them what they need to make it well.

Examples:
- "Create vault" — not "Get started"
- "Last check-in: 3 days ago" — not "You're all caught up!"
- "Funds will release to the named beneficiary if you do not check in within 90 days." — not "Set it and forget it!"
